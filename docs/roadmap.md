# Roadmap

The next engineering milestones should be driven by external experiment needs:

1. Publish a benchmark adapter and conformance suite only after its state/action/event contract is demonstrated by a second independently useful domain.
2. Connect closed-loop execution to an explicitly validated higher-fidelity propagation adapter while retaining the immutable `spacecraft-coordination-v1` meaning.
3. Add uncertainty/covariance-aware risk models with unambiguous metric names and reference validation cases.
4. Expand decentralized protocols and network topology/fault models with controlled random streams.
5. Add full state-reconstruction replay and scale testing.
6. Activate archival DOI releases and accumulate independently reproduced studies and adoption evidence.
7. Extend the artifact-driven viewer only as researchers identify additional causal questions and standard trace requirements.

Further visualization breadth should be driven by observed researcher workflows rather than generic dashboard features.
